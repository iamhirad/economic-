# جزوه مبانی اقتصاد: اقتصاد خرد

جزوه کامل فارسی بخش اول درس **مبانی اقتصاد** (اقتصاد خرد، ۷۹ اسلاید)، بر پایه اسلایدهای درس دکتر علی ابراهیم‌نژاد (دانشگاه صنعتی شریف). جزوه دانشجویی و غیررسمی است.

- **نسخه PDF:** [`jozve-mabani-eghtesad.pdf`](jozve-mabani-eghtesad.pdf) (۱۱۵ صفحه، راست‌به‌چپ، با فهرست صفحه‌دار و بوکمارک)
- **نسخه وب:** [`index.html`](index.html) (با فهرست کناری، حالت تیره، و پاسخ‌های بازشونده)

## محتوا

| فصل | موضوع | اسلایدها |
|---|---|---|
| ۱ | مقدمه: کمیابی، ده اصل اقتصاد، سازوکارهای تخصیص، علیت و همبستگی، اقتصاد اثباتی و هنجاری | ۳ تا ۹ |
| ۲ | عرضه و تقاضا، برآورد تقاضا (طلا، هارلی‌دیویدسون، فدرال رزرو، L’eggs)، پنبه و گاز، تعادل | ۱۰ تا ۳۱ |
| ۳ | کشش قیمتی، درآمدی و متقاطع؛ کشش و درآمد کل؛ مثال کشاورزان و مواد مخدر | ۳۲ تا ۴۷ |
| ۴ | مازاد مصرف‌کننده و تولیدکننده، تبعیض قیمت، روش‌های قیمت‌گذاری، چوب ارزش، زیان رفاهی | ۴۸ تا ۶۲ |
| ۵ | سقف و کف قیمت، مالیات و بار آن، منحنی لافر، یارانه، سهمیه، تعرفه، پیامد خارجی، کالای عمومی، هزینه مبادله | ۶۳ تا ۷۹ |
| ۶ | فرمول‌نامه، اشتباه‌های رایج، مسائل جامع، مرور «چرا»ها، واژه‌نامه | همه |

هر فصل شامل توضیح کامل، کادرهای «چرا؟» و «چگونه؟»، مثال‌های حل‌شده (همه مثال‌های اسلایدها با عدد) و تمرین با حل تشریحی است. همه نمودارها از روی همان معادله‌های مثال‌ها رسم شده‌اند.

## نمایش به‌صورت صفحه وب (GitHub Pages)

در تنظیمات مخزن: **Settings → Pages → Build and deployment → Source: Deploy from a branch**، شاخه‌ای که این فایل‌ها در آن است و پوشه `/ (root)` را انتخاب کنید. بعد از چند دقیقه جزوه در آدرس `https://iamhirad.github.io/economic-/` در دسترس است.

## ساختن دوباره

منبع جزوه در پوشه `src/` است (فصل‌ها در `src/chapters/`، نمودارها در `src/figs.py`).

```bash
cd src
npm install                 # KaTeX برای فرمول‌ها
pip install pypdf
python3 build.py --pdf      # index.html و PDF را می‌سازد (به Playwright/Chromium نیاز دارد)
```
